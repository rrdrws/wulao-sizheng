# 薪火相传｜“五老”精神数字思政平台（演示原型）

一个可直接发布到 GitHub Pages 的静态演示网站，用于课题答辩、项目演讲和原型展示。

## 功能

- **五老访谈馆**：模拟人物卡片、主题筛选、关键词搜索、访谈详情和教学场景。
- **思政资源库**：模拟微视频、文字、图文、音频资源；分类搜索、使用建议、收藏。
- **AI赋能工作台**：输入访谈文字，一键演示摘要、主题标签、微视频脚本流程；可切换查看和复制。
- **运营与反馈**：模拟数据图、主题投票与即时结果反馈。
- **内容审核说明**：明确“受访者本人确认—关工委审核”的上线要求。
- 移动端适配。

> **特别说明**：这是纯前端演示站点。人物姓名、故事、图像、资源和运营统计均为模拟或占位内容；微视频/音频只是播放区占位，**没有真实媒体文件**；AI模块采用本地关键词规则及模板，不调用真实大模型；收藏、反馈均不保存，刷新页面会重置。不得在课题成果报告中将模拟内容表述为已采集访谈或已获取试运行数据。

## 目录

```text
index.html  # 页面结构
style.css   # 页面设计和移动端适配
app.js      # 模拟数据与交互功能
preview.py  # 本地可选预览工具（GitHub 不需要）
README.md   # 项目说明和部署教程
.nojekyll   # GitHub Pages 静态资源兼容标记
```

## 本地打开

可以直接双击 `index.html`。也可以在此目录运行 `python preview.py`，然后访问 http://127.0.0.1:8000/。关闭 Python 不会影响 GitHub Pages 上线网站。

## 发布到 GitHub Pages：无需服务器，也无需运行 Python

1. 打开 https://github.com/ 注册或登录账号。
2. 点击右上角 `+` → **New repository**，仓库名建议 `wulao-sizheng`，选择 **Public**，然后创建仓库。
3. 点击 **Add file → Upload files**，上传 `index.html`、`style.css`、`app.js`、`README.md` 和 `.nojekyll`（上传 ZIP 压缩包本身不会自动解压，需要上传其内部文件）。也可以直接用 Git 推送。
4. 进入仓库 **Settings → Pages**，在 **Build and deployment** 下设置 **Source: Deploy from a branch**，选择 **Branch: main**、**Folder: / (root)**，点击 **Save**。
5. 等待 GitHub 完成首次发布；页面会显示可访问的网址，格式通常是：`https://你的用户名.github.io/wulao-sizheng/`。这只是网址格式举例，**实际网址需以 GitHub Pages 显示为准**。
6. 以后更新网站，只需替换仓库中的 `index.html` / `style.css` / `app.js`。无需维持本地服务器或电脑开机。

**注意**：此方案需要将仓库文件上传至 GitHub，并开启 Pages。当前交付的是可上传的项目文件，未代替你登录 GitHub，也未创建实际线上地址。首次部署一般需要短暂的构建发布过程。

## 替换正式素材

- `app.js` 中 `interviews` 对象数组：替换为已授权的受访者信息、真实转写稿、主题及教学建议。
- `app.js` 中 `resources` 数组：替换为已审核的教学资源描述。
- 真实视频如 `media/video01.mp4`，可以后续将占位元素改成 `<video controls src="media/video01.mp4"></video>`。请留意 GitHub 仓库对大文件的限制；真实视频多时建议使用机构允许的媒体托管服务。
- 真实语音转写、摘要、智能脚本生成需要第三方 AI API 或后端部署，不宜在公开前端代码中直接存放 API Key；纯 GitHub Pages 无法安全承载私密 API 密钥。
- 若要跨用户持久化留言、收藏、反馈统计，需要另接后端/数据库或托管服务。

## 演讲时建议的操作顺序

首页概览 → 访谈馆按主题筛选并打开人物故事 → 资源库筛选微视频并打开详情 → AI 工作台点击模拟生成，切换摘要和脚本 → 平台成效查看示例图并提交一次反馈 → 讲解“受访者确认—关工委审核”机制。
